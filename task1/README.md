## Описание работы
Создание одностраничного резюме/портфолио с использованием чистых семантических тегов HTML5 и современного подхода к раскладке элементов на базе **Flexbox**.

### Реализованные блоки:
1. **Шапка (`<header>`)** — имя, специальность и краткий слоган.
2. **Аватар** — графическое представление пользователя.
3. **Блок «О себе» (`<section>`)** — краткая автобиография.
4. **Блок «Образование»** — структурированный список учебных заведений и годов обучения.
5. **Блок «Навыки»** — набор визуальных тегов («пилюль») с использованием кастомных стилей.
6. **Блок «Контакты» (`<footer>`)** — интерактивные ссылки (`mailto:`, `тел.`, соцсети) с эффектами наведения (`:hover`).
7. **Навигация (`<nav>`)** — якорные ссылки для быстрого перемещения по разделам страницы.

### Технические особенности:
* Использование исключительно семантических тегов структуры без «голых» `<div>` для разметки крупных блоков.
* Полная раскладка выполнена на `display: flex` (с задействованием свойств `justify-content`, `align-items`, `flex-direction`, `flex-wrap`, `gap`).
* Глобальное применение `box-sizing: border-box`.
* Отсутствие JavaScript, таблиц и плавающих элементов (`float`, `position: absolute/fixed`).
