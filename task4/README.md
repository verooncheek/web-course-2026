# Лабораторная работа №4. Игра «Быки и коровы»

## Информация о студенте
* **ФИО:** Билина Вероника Юрьевна
* **Группа:** Механико-математический факультет БГУ

## Описание работы
Реализация логической классической игры «Быки и коровы» на чистом JavaScript с полным управлением состоянием приложения, историей ходов и валидацией пользовательского ввода.

### Правила и игровой процесс:
1. При старте игры компьютер генерирует случайное 4-значное число с уникальными (неповторяющимися) цифрами от 0 до 9.
2. Игрок вводит свои варианты с помощью поля ввода и кнопки «Проверить».
3. **Валидация:** Проверяется длина строки (строго 4 знака), отсутствие букв/символов и уникальность каждой цифры. Ошибки выводятся на экран, некорректные попытки не засчитываются в историю.
4. **Подсчёт результатов:** После каждого успешного хода алгоритм вычисляет количество:
   * **Быков** — цифра угадана и находится на своём месте.
   * **Коров** — цифра присутствует в загаданном числе, но стоит на другой позиции.
5. **История и счётчик:** Все попытки логируются в массив данных и отображаются в виде структурированного списка с правильным склонением русских слов («бык/быка/быков», «попытку/попытки/попыток»).
6. **Победа и перезапуск:** При отгадывании всех 4 цифр игра блокирует поле ввода, выводит победное сообщение и предлагает сыграть заново без перезагрузки страницы по кнопке «Новая игра».

### Технические особенности:
* Чистая модульная архитектура на функциях: раздельная генерация, валидация, подсчет очков и рендеринг.
* Рендеринг истории ходов на основе массива состояния.
