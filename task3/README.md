## Описание работы
Создание интерактивного списка задач (To-Do List) с динамическим управлением DOM-деревом и состоянием интерфейса на чистом JavaScript.

### Основная функциональность:
1. **Добавление задач:** Реализовано через форму (кнопку «Добавить» и клавишу `Enter`). Встроена валидация: пустые строки не допускаются.
2. **Управление состоянием задачи:**
   * Отметка о выполнении через интерактивный чекбокс (визуальное зачёркивание с изменением прозрачности через CSS-класс `.completed`).
   * Кнопка удаления отдельной задачи из общего списка.
3. **Счётчик задач:** Динамическое отображение оставшихся и выполненных задач в формате *«Осталось: N | Выполнено: M»*.
4. **Фильтрация:** Переключение между тремя режимами отображения списка с помощью кклавиш-фильтров («Все», «Активные», «Завершённые») через скрытие элементов без удаления их из массива данных.

### Технические особенности:
* Вся бизнес-логика и отрисовка сосредоточены в файле `script.js`.
* Хранение данных организовано в виде массива объектов в памяти JavaScript.
* Отрисовка интерфейса реализована через универсальную функцию `render()` с активным использованием методов массивов (`map`, `filter`, `forEach`).
* Каждой задаче присваивается последовательный числовой идентификатор (`id`).
* Обработка всех событий выполнена современным методом `addEventListener`.
