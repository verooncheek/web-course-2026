# Лабораторная работа №5. Игра «Симон говорит» (Simon Says)

## Информация о студенте
- **ФИО:** Билина Вероника Юрьевна
- **Группа:** Механико-математический факультет БГУ

## Описание работы
Реализация классической аркадной игры на память и реакцию «Симон говорит» (Simon Says) на чистом JavaScript с неоновой ретро-стилистикой, процедурной генерацией 8-битного звука и управлением состоянием приложения.

### Правила и игровой процесс:
1. **Старт игры:** Игрок нажимает кнопку «СТАРТ», после чего начинается первый раунд.
2. **Демонстрация последовательности:** В каждом раунде игра добавляет к текущей цепочке один случайный цветной сектор (из четырёх доступных) и поочерёдно подсвечивает всю последовательность, сопровождая каждый цвет уникальным звуковым сигналом. На время показа ввод игрока блокируется.
3. **Ход игрока:** После завершения демонстрации появляется подсказка «ТВОЙ ХОД!», и игрок должен точно повторить показанную комбинацию, нажимая на соответствующие цветные сектора.
4. **Переход к следующему раунду:** При безошибочном повторении всей цепочки игра выводит сообщение «ОТЛИЧНО!», увеличивает счётчик раундов и переходит на следующий уровень, удлиняя последовательность.
5. **Поражение и перезапуск:** Если игрок нажимает неверный сектор, игра завершается (сообщение «GAME OVER!» с номером достигнутого раунда, визуальный эффект глитча и низкий звуковой сигнал ошибки). В любой момент игру можно начать заново с помощью кнопок «СТАРТ» или «СБРОС» без перезагрузки страницы.

### Технические особенности:
- **Процедурный синтез звука (Web Audio API):** Звуковые эффекты генерируются программно в реальном времени через `AudioContext`, осцилляторы с прямоугольной формой волны (`square`) и плавное затухание громкости (`GainNode`) без использования внешних аудиофайлов.
- **Безопасное управление таймерами:** Реализована система отслеживания и централизованной очистки отложенных вызовов (`later` / `clearTimers`), исключающая наложение анимаций и гонку таймеров при сбросе или перезапуске игры.
- **Управление состоянием (State Management):** Единый объект состояния контролирует текущую последовательность, прогресс игрока в раунде, номер уровня и блокировку пользовательского ввода во время хода компьютера.
- **Адаптивный ретро-интерфейс:** Стилизация в духе киберпанка/синтвейва с использованием CSS Grid, неоновых теней (`box-shadow`), плавных переходов и анимации глитча при поражении.
