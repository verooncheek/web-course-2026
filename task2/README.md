## Описание работы
Разработка адаптивного одностраничного лендинга с применением методологии **Mobile First** и современных раскладок **CSS Grid** + **Flexbox**.

### Реализованный функционал и структура:
1. **Адаптивность под три контрольные точки:**
   * Мобильные устройства (до `767px`).
   * Планшеты (`768px` – `1199px`).
   * Десктопы (от `1200px`).
2. **Макетная сетка:** Крупные структурные блоки страницы спроектированы с помощью `CSS Grid`, а мелкие компоненты (карточки, навигация, кнопки с иконками) выстроены через `Flexbox`.
3. **Интерфейсные элементы:**
   * Меню с адаптивным отображением (заготовка под «гамбургер» на мобильных экранах).
   * Интерактивная форма обратной связи (поля «Имя», «Email», «Сообщение» и кнопка отправки) с проработанными состояниями `:hover` и `:focus`.
4. **Плавные анимации:** Добавлены свойства `transition` для интерактивных элементов интерфейса.

### Технические особенности:
* Написание стилей строго по стандарту *Mobile First* с использованием `@media (min-width: ...)` без использования ограничений `max-width`.
* Отсутствие горизонтального скролла на любых экранах, размеры интерактивных элементов оптимизированы под сенсорные экраны (touch-friendly).
